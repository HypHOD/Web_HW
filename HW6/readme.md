实现上方界面中所示的树、列表和两个按钮及相关功能，要求如下：
1. 通过ajax的方式(post或get均可)从网址(http://ext.gaomuxuexi.com:5870/task/nodes)获取数据，分别显示为树和列表
2. 点击刷新按钮则重新获取数据并重新显示

操作(下述功能至少实现1～2，实现功能越多，用户交互越好，得分越高)
1. 树或列表中内容多时可上下滚动查看；树的节点能够通过鼠标点击收起或展开下级内容
2. 能够通过拖动将列表中的条目拖动到树的节点上，成为该节点的子节点；条目从列表中消失
3. 能够通过拖动将树上的节点拖动到列表中，则该节点及以该节点为根的子树中的所有节点成为列表中的条目；同时该子树从树中删除；（树的根节点不允许被拖动）
4. 能够在列表中选中多个条目拖动到树的节点上成为子节点
5. 能够在树上拖动节点A到节点B上，使得A成为B的子节点（整个以A为根的子树应一起移动）；但不允许不合理的拖动，如：B是A的后代节点，则A不能拖动成为B的子节点
5. 点击提交按钮则通过ajax的post方式将当前的树和列表中的内容（注意：可能是经过了拖动、删除等操作后的内容）提交数据到网址(http://ext.gaomuxuexi.com:5870/task/nodesCommit)并用合适的方式显示返回信息
    POST提交数据使用的content-type应该为：application/x-www-form-urlencoded;charset=utf-8
    POST的数据包括以下参数
        list:当前列表中的数据，值为JSON.stringify(x)，其中x的格式和通过/task/nodes接口得到的返回中的list是一致的
        tree:当前列表中的数据，值为JSON.stringify(x)，其中x的格式和通过/task/nodes接口得到的返回中的tree是一致的
UI颜值会在分数中占一定比值
    节点列表中的条目有四种类型:1=空心圆2=实心圆3=空心方形4=实心方形
    树的根节点类型永远为0，图标必须不同于以上四种；
    UI美化可以改变不同类型的图标，但必须保证能够辨别出来这是空心圆、那是实心方块等
